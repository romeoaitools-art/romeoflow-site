# Romeo.Flow — Site vitrine

Site vitrine one-page pour Romeo.Flow, consultant en automatisation IA pour l'immobilier.

- `index.html` — le site complet, autonome (logo et photo intégrés, aucune dépendance externe)
- `og-image.jpg` — image d'aperçu pour le partage sur les réseaux sociaux

## Déploiement

Ce dépôt est prévu pour un déploiement continu via Netlify : chaque `git push` sur `main` republie automatiquement le site.

## Domaine

romeoflow.com (à connecter dans les paramètres Netlify une fois le domaine acheté).
